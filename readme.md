# nightshift-os

> Built for developers still awake at 3AM.

nightshift-os is an experimental productivity workspace focused on creating a calmer late-night development environment.

The project combines lightweight productivity tools with ambient visuals, terminal utilities, and focused workspaces designed for long coding sessions.

---

## Why I Built This

I wanted a workspace that felt less corporate and more atmospheric.

Most productivity tools optimize for task management.  
This project experimented with optimizing for mood, focus, and quiet late-night sessions instead.

---

## Stack

- Next.js
- Electron
- Tailwind CSS
- Zustand
- Supabase
